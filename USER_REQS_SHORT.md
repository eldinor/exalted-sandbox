# Exalted Sandbox: system requirements

Explore Exalted directly in your browser. No game installation or browser
plugin is required.

## Hardware

| Component | Minimum target | Recommended |
|---|---|---|
| Computer | Desktop or laptop | Desktop or laptop with dedicated graphics |
| Processor | Modern 4-core CPU | Modern 6-core CPU or better |
| Memory | 8 GB RAM | 16 GB RAM or more |
| Graphics | WebGPU-capable GPU; 4 GB dedicated graphics memory as a starting target | WebGPU-capable GPU with 8 GB graphics memory or more |
| Display settings | 1280 x 720, Balanced quality | 1920 x 1080, High quality |
| Controls | Keyboard and mouse with a right button | Keyboard and mouse with a scroll wheel |

These are provisional targets. Performance varies by device, browser and
settings; a particular frame rate is not guaranteed. Integrated graphics may
work but have not been established as a supported minimum.

## Browser and connection

- **Recommended browser: current Google Chrome**, with hardware acceleration
  enabled and an up-to-date graphics driver.
- Current Firefox can also be used on compatible systems; performance may differ.
- WebGPU must be available on your device. Browser support alone does not
  guarantee that its graphics hardware meets the app's requirements.
- Use a stable internet connection. **25 Mbps or faster** is recommended for
  a shorter first load; slower connections may take longer.
- Phones, tablets and touch-only controls are not currently supported.

## If performance is low

Press **F1**, select **Balanced** quality and lower the rendering resolution.
On a laptop, use mains power and select the dedicated GPU where available.

Use the **?** button in the upper-right corner for movement and spell controls.
