# Exalted loading-screen logo

`exalted-logo.svg` is the unmodified SVG supplied by the project owner for the
main app loading screen on 4 November 2026.

Source: https://raw.githubusercontent.com/eldinor/ForBJS/master/Exalted_Logo_Gold_Purple_Crown_A_Flat.svg

Served locally and included in the production asset inventory. The loading
screen displays it at up to 220 CSS pixels wide, retaining its original aspect
ratio and the existing entrance animation.

The top navigation also uses this logo in a 93 by 32 CSS-pixel box, linked to
https://alpha.exalted8.com/ in the same tab, with no instruction text beneath it.
The navigation panel retains its 48-pixel height.

`favicon.svg` extracts the original purple crown path without changing its shape
or colour, framed in a square SVG viewBox for the browser tab icon.
