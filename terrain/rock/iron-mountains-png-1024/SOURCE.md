# Browser-loaded rock PNGs

Generated by `npm run assets:rocks:png` from the preserved five-layer package
in `../iron-mountains-1024/`. Original textures and packed arrays are read-only.
See `../iron-mountains/SOURCE.md` and THIRD_PARTY_NOTICES.md for attribution/terms.

All images are untagged 1024-square opaque PNGs. Base, normal and ARM retain
their exact RGB8 values. Height is grayscale8, reconstructed into ARM alpha
after browser decoding to avoid alpha premultiplication changing RGB values.
Layer order and physical scales are recorded in textures.json, with checksums
for the preserved sources and every generated image. No pixels are resampled.

Production and development download images sequentially and use browser PNG
decoding; the custom gzip response stream is no longer part of rock loading.
The three GPU arrays and their explicit per-layer mipmaps remain unchanged.
