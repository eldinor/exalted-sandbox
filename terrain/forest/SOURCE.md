# Pine tree source

## Forest ground textures

`textures/forrest_ground_01_*` were supplied by the user for the forest biome.
The main app uses `diff_2k.png` (sRGB colour), `nor_gl_2k.png` (linear OpenGL
normal) and `arm_2k.png` (linear AO/roughness/metallic). The separate AO PNG
remains a source reference. Unused EXR normal/roughness copies were removed on
9 November 2026; retained PNGs are unchanged.
no external download or inferred source licence is added. Original creator,
source URL and licence for these ground maps have not been provided.

Runtime tiling/blending is recorded in [FOREST_NOTES.md](../../../FOREST_NOTES.md).
Heightmap biome blending uses the separately generated
`public/assets/textures/ground-coverage-9.png`; its source hash, channel contract
and regeneration steps are documented in [BIOMES_MAPS.md](../../../BIOMES_MAPS.md).

## Original pine reference

`pine_tree_01.glb` was supplied in this repository by the user. Its embedded
metadata names a Sketchfab export (`pine tree 01.obj.cleaner.materialmerger.gles`)
with one merged mesh, two tree shapes, and embedded PBR textures. A 2026-10-12
licensing audit found embedded `asset.extras` crediting Digital screen official
(https://sketchfab.com/ck212575), CC BY 4.0, source:
https://sketchfab.com/3d-models/pine-tree-01-ba7c8f8e1cb549b3a3a30f1221386c8c.
See the root THIRD_PARTY_NOTICES.md for consolidated attribution.

The initial Forestland lab read this file and separated geometry in memory.
The original asset is retained unchanged as a reference.

## Pine pack

`pine_trees_pack_lowpoly_game_ready_lods.glb` is the user-supplied original pack.
Its embedded metadata credits **LOLIPOP** and states **CC BY 4.0**:

- Creator: https://sketchfab.com/lolipop_1707
- Source: https://sketchfab.com/3d-models/pine-trees-pack-lowpoly-game-ready-lods-e1e9c07b8e2e445c943fec660beefba2
- Licence: https://creativecommons.org/licenses/by/4.0/

`pine-pack-forestland.glb` is generated by `node scripts/prepare-pine-pack.mjs`.
It retains the three variants of medium, big, small and sapling pines at LOD1
and LOD2, with separate bark/foliage. LOD0, LOD3 billboards, large pines and
reference geometry are excluded. Display translations are removed while
axis/unit transforms are retained. Foliage uses alpha cutout (threshold 0.35).
Selected accessors are repacked; normals, tangents, UV channels and six shared
embedded texture images are preserved. The derived GLB contains the source
SHA-256 in `asset.extras` and is about 22.7 MB, compared with the 46.2 MB source.
Forestland displays creator/licence attribution. Original files are unchanged;
no external asset was downloaded.

## Selected coniferous details

`coniferous_forest_assets_pack.glb` is a user-supplied pack whose metadata credits
Dari (https://sketchfab.com/dariiiii) and CC BY 4.0. Five initial detail assets
are saved in `coniferous-selected/`: a fallen log, two dead trees, and individual
mossy/plain boulders. Their six PNG maps are shared externally in `textures/`.
See [coniferous-selected/README.md](coniferous-selected/README.md) for attribution,
original source URL, retained transforms/materials, and regeneration instructions.
They are not integrated into the app or Forestland yet.


The main app's authorized closed eastern-forest trial also uses the prepared
pack, selecting only `Pine_big_1` LOD1/LOD2 through the shared production loader.
It retains the source materials, textures and the LOLIPOP / CC BY 4.0 attribution
above; the original source and prepared asset are unchanged.


## Blue spruce

The user-supplied `blue_spruce.glb` credits RosticOstafi / CC BY 4.0 in its
embedded metadata. The derived alpha-cutout GLB and WebGPU-baked colour/normal
impostor atlases live under `blue-spruce/`. Original bytes remain unchanged.
See [blue-spruce/README.md](blue-spruce/README.md) for source/creator/licence links,
derivation, regeneration and the seventeen ground/aerial capture views.


## Realistic fir subset (2026-10-12)

User-supplied source under `public/assets/exalted/realistic_fir_trees_pack_lods_gameready.glb`.
LOLIPOP, CC BY 4.0, source:
https://sketchfab.com/3d-models/realistic-fir-trees-pack-lods-gameready-f58e8b6d733e4b0586e5b7db847b89e7.
Derived `fir-pack-selected.glb` contains Large 2, Medium 1/2 and Small 1/2,
LOD1/LOD2, source textures and preserved attribution. Preparation clears display
offsets, renames selected nodes and changes foliage BLEND to MASK 0.35.
See `fir-pack-selected.README.md` and `scripts/prepare-fir-pack.mjs`.
