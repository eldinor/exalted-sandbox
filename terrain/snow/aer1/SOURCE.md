# Tested rock-snow texture reference

User supplied snow_01 colour, OpenGL normal, packed ARM and standalone AO maps.
Creator, source URL, licence and physical width were not supplied; confirmation
remains pending in THIRD_PARTY_NOTICES.md. No licence is inferred from filenames.

This set was tested on Snow Mountains cliffs using triplanar projection, then
reverted at the user's latest instruction to retain Rock Face 03 and current
snow. The originals remain unchanged and are not loaded by production.
The current snow surface remains procedural; Palecrown reserve and steep-face
normal correction are retained. See SNOW_MOUNTAINS.md for current integration.
